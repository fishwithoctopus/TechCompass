01 / 带入背景

从 Agent 会话开始

接入 MCP 后，让 Agent 注册当前项目。也可以选择本地文件夹，扫描后确认摘要，不必先填一整份档案。

02 / 看清差别

不止解释“是什么”

查技术，看它在项目里能替代或补充什么。查模型，看与旧版相比的变化、代价和升级建议。

开始之前：模型、联网与隐私
