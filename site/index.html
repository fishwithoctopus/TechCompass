给正在用 AI Agent 做产品、写代码的人。
项目背景保存后，不必每次从头解释。

  1. 关联项目

    选择项目目录，读取 README、依赖与近期提交，提炼目标、技术栈和当前阶段。支持查看、纠正和刷新，也可通过 MCP 让 Agent 写入项目摘要。

  2. 输入刚看到的东西

    一个技术词、一条 GitHub 链接，或者一张新闻截图。图片可以选择文件、拖入，也可以直接粘贴。

  3. 决定现在要不要用

    先解释它是什么，再逐项目判断相关度、替代或补充的位置。值得用就给验证动作；暂时不需要，就说明什么时候再看。

使用前需要知道

分析可调用本机已安装并登录的 Codex / Claude Code，也可在设置中添加兼容 API 的地址、模型与 Key。当前关键词联网检索依赖 Codex；自定义 API 并不自动提供搜索。

模型分析与联网检索会使用相应服务及额度，并非承诺免费。项目记录与分析历史保存在本机；用于分析的内容会发送给你选择的模型服务。网页演示不是桌面程序，也不会自动关联项目。
