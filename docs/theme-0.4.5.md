# 0.4.5 外观整理

- 线性指南针：开口圆环和空心指针，无中央圆点。SVG、Windows ICO、PNG 和 macOS 模板图标由同一几何源生成。
- 设置 → 外观：跟随系统、浅色、深色。选项本机保存，页面加载前恢复，系统模式监听明暗变化。
- 使用语义颜色覆盖文字、面板、输入、导航、提示、错误、徽章、主按钮、滚动条和选区。Mac 托盘使用模板图标适应系统菜单栏。
- 统一 margin/padding/gap 到 4px 倍数，项目与历史卡片内边距 16px、间距 12px。边框、字号、图标尺寸和窗口外壳高度不作为间距强制取整。
- 精简重复解释，搜索额度按需展开，保留密钥、费用、权限和数据发送提示。中文界面分号改为逗号，不修改代码分号或已有用户历史。
- Windows 加密文案改为“操作系统加密”，窄屏提示不再限定 Windows。

验证：96 项测试通过，包含主题切换与持久化断言。400×580 浏览器检查浅色设置、项目表单、项目与历史卡片、深色项目页。两类卡片实测 16px/12px，控制台无错误。对比度：浅色次级文字 4.8981:1、主按钮文字 5.8527:1、浅色警告 6.1874:1、深色次级文字 5.8374:1、深色控件边界 3.5946:1。Mac 真机、原生菜单栏与系统滚动条偏好仍待实机验收。
