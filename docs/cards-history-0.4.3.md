# 0.4.3：项目卡片、历史分组、接入配置

- 项目默认折叠成名称、状态、一句话目标卡片；点击展开路径、资料和管理操作。已有项目时注册说明默认收起，空状态保留引导。
- 最近 100 条历史按相同输入分组，不删除结果。文本忽略大小写与多余空白；链接保留路径大小写和查询参数；截图及缺少输入的记录单独保留。不会根据模型生成的近似标题猜测合并。
- 设置中的 MCP 区增加本机 stdio JSON 配置及给 Agent 的接入说明复制入口。配置来自实际运行时，不包含模型密钥或本地 HTTP token，不自动更改客户端配置。
- 该入口不是远程 URL，也不保证任何客户端都支持 JSON 导入；Codex 等客户端可能需要转换格式。HTTP MCP 链接属于后续独立能力，需要生命周期、认证及客户端兼容验证，本版不开放公网服务。

验证：自动化测试覆盖卡片默认折叠、历史分组与路径大小写隔离、截图不合并、配置复制。浏览器使用隔离临时目录检查卡片展开；没有更改真实 Agent 配置或用户项目数据。
