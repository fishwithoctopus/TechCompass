# 0.4.4：本机 MCP 地址与统一界面

在设置 → MCP 接入 → 通过地址接入，复制当前实际端口的地址和连接密钥。
客户端选择 Streamable HTTP，配置 `Authorization: Bearer <连接密钥>` 请求头，或在 Bearer Token 输入框只填密钥。密钥不在 URL 中，不要公开分享。

接口绑定本机 127.0.0.1。TechCompass 必须运行；端口被占用时可能变化，请以设置显示为准。此接口服务于本机客户端，不是公网服务；纯云端、仅支持旧 HTTP+SSE 或不能设置鉴权头的客户端不在本版兼容范围内。仍可使用原有 stdio 配置。不要关闭鉴权来兼容客户端。

通过 MCP 可注册本地项目、读取已注册摘要、获取分析规则、保存分析。连接密钥只应交给可信 Agent。HTTP 与 stdio 共用工具定义和用户存储。支持协议不等于每一家客户端已实测；本版通过官方 SDK 的 initialize、tools/list 及四项工具调用验证，未改动真实 Codex 配置。

安全检查：错误密钥 401、跨站 Origin 与错误 Host 403、不支持的方法 405、非法 JSON 400，限制请求大小。连接密钥与卡片 HTTP 管理 token 隔离。

界面：项目、历史、设置标题栏统一 58px；去掉设置外层 panel；品牌图像和文字居中对齐。窗口、托盘、Windows exe 图标来自 build/icon.png/icon.ico 同一生成源，修复 ICO 缩小时红蓝通道颠倒。便携打包会写入 exe 图标资源，不再保留 Electron 默认图标。Windows 旧快捷方式缓存或已运行旧进程不会自动刷新，需要指向新版并重启应用。

验证：96 项测试通过；400×580 浏览器中三个标题栏实测高度相同，logo 与文字中心一致，设置外层无边框。新版包 MCP 模块加载通过；原生托盘与 Mac 真机视觉需另行确认。
