# TechCompass 下一阶段完善与 macOS 支持

本轮基于 0.3.2 源码追加 Mac 适配，尚未发布新版本。既有 Windows 下载不变。目标是把作品完善为别人能独立安装、理解和持续使用的小工具。

## P0 首次使用与信任

- 接入状态拆成已发现工具、已登录、可分析、可联网、MCP 已注册、MCP 可调用，不能用单个“已接入”替代。提供不改配置的连接测试和恢复指引。
- 首次关联项目时，先展示自动提取的摘要，再只请用户确认当前目标与阶段。支持自定义 CLI 路径；不要承诺自动理解所有项目。
- MCP 注册必须预览、备份、解析校验、并发保护与可回滚；继续保留现有隔离事故回归测试。演示和真实结果不能混用。
- 验收：一位未参与开发的人，在不用开发者解释的情况下完成关联、真实分析、退出与重新打开；失败时知道下一步。

## P1 判断质量与上下文

- 项目当前重点比 README 更容易过期。展示摘要时间、信息来源与可纠正字段，刷新前后能比较；优先提示变更，不静默全盘扫描。
- 每条建议明确引用项目事实。把已核实的技术事实、模型推断、待确认项分开；相关度不是精确概率，热度不是推荐理由。
- 加入小型固定评测集：同名术语、过时项目、无关热点、相关但迁移不划算、资料不足。人工检查事实引用与建议可执行性。
- 反馈 UI 暂不恢复。不宣称“越用越懂”；若以后引入，应明确收集用途、授权、删除方式和是否影响下次判断。

## P1 等待与成本

- 展示真实阶段与已耗时，提供取消；先呈现可核实的定义，再补项目判断需要新增流式协议，不能拿假进度代替。
- 对公开资料和项目判断分别缓存，项目改变时只失效必要部分；显示是否使用缓存及资料日期。
- 采集多次真实请求的中位数、慢请求比例和失败率，避免用单次 31 秒当稳定速度承诺。
- 联网服务应逐步独立于 Codex，用户选择其他模型时不必仍安装 Codex；这是后续功能，不是当前已实现能力。

## P2 界面与公开视频

- 桌面卡片仍是暗色，与新版浅色主页不完全一致。下一轮统一控件、字号、状态和空白页，优先让输入入口与当前项目更明显。
- 支持来源检查、历史重分析和清理；多项目时避免整屏长报告，可先看当前项目。
- 用真实个人项目录视频，展示一次有依据的“以后再看”。不展示公司代码、Key 或账户信息；剪掉等待时应说明。

## macOS 本轮已改的源码

- 增加 arm64（Apple Silicon）和 x64（Intel）的独立 DMG / ZIP 构建命令。
- 补充 Finder 环境下常见 CLI 安装目录及子进程 PATH，保留现有 Windows 检测。
- Mac 使用 Command+Shift+T，增加原生编辑菜单支持复制粘贴、Dock 激活显示与正常退出。
- 添加平台单元测试和手动触发的 Mac CI 构建工作流；只产出测试附件，不自动发布 Release。

## 尚未完成 不能当成 Mac 正式版

- 当前开发机为 Windows，尚无真实 Mac 安装包构建成功证据，也未完成 Finder 启动、截图粘贴、Keychain、模型登录、目录权限、菜单栏与多显示器走查。
- Apple Developer 签名与 notarization 尚未配置。预览构建不能宣称已公证；正式分发前需完成签名、公证和干净机器验证，不要求用户关闭 Gatekeeper。
- 原有宿主配置写入必须在 Mac 隔离目录重测；程序移动到 Applications 后再注册 MCP，避免记录临时 DMG 路径。
- 用户已授权按 MIT 完整开源。源码与手动 Mac 构建工作流已纳入仓库；构建成功与真实 Mac 验收仍须分别记录。

## 在 Mac 构建和验收

Node.js 20+，在源码根目录运行 `npm ci`、`npm test`，然后按机器架构执行 `npm run dist:mac:arm64` 或 `npm run dist:mac:x64`。输出在 dist/。测试构建可设置 CSC_IDENTITY_AUTO_DISCOVERY=false；正式版应配置开发者签名与公证。

验收顺序：安装到 Applications → Finder 冷启动 → 原生目录选择 → 确认项目摘要 → 检测与登录模型 → 技术词联网并查看来源 → 图片选择及 Command+V → 取消或失败恢复 → Keychain 保存与重启 → 菜单栏收起及退出 → 隔离 MCP 注册及恢复。Apple Silicon 和 Intel 分别记录结果；未通过前不把主页改成“Mac 已支持”。

官方参考：https://www.electronjs.org/docs/latest/tutorial/menus ，https://www.electron.build/mac/ 。本项目保持 electron-builder 25 配置格式，不照搬新版的签名配置结构。
