- 页首先说明 Agent 会话注册，提供复制指令、接入设置与刷新列表入口；不会自动修改 Agent 配置。
- 将含糊的“关联项目”改为“从文件夹关联”，说明与 Agent 注册是两条可选路径。
- 扫描前隐藏空白资料字段，扫描后展示摘要与纠正项；高级资料保持折叠。
- 编辑时隐藏入口说明和项目列表，保存或取消后恢复；统一字段、按钮与分组间距。
- 移除关联明确不会删除本地项目文件。
- 修复滚动容器顶部留白造成的吸顶标题透出正文问题。

验证：95 项自动化测试通过（新增项目页入口、复制、分步表单断言）；独立临时数据下浏览器实测 400×580，完成扫描、纠正与保存。滚动后标题顶边和导航底边均为 54px，项目页无横向溢出，控制台无错误。不涉及真实 Agent 配置写入或新的付费模型调用；Electron 原生窗口仍待用户目视确认。
