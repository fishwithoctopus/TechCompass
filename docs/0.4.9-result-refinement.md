# 0.4.9 本地测试版

- 模型类词条增加明确基准、最多三条变化及实际影响、代价、升级建议和对比来源。
- 搜索和分析提示均要求核实新旧版本，不假定用户正在使用某个旧型号。缺少证据时明确无法可靠比较。
- MCP rubric、输入 schema、保存契约和桌面展示同步支持模型对比字段。
- 完全无关的项目不再显示。相关性与采用建议仍然独立，medium + ignore 的项目仍可显示。
- 保留内部完整判断和历史快照，不删除项目。没有匹配项目时展示词条的具体假设应用场景。旧结果没有场景字段时提示重新分析。
- 身份不明继续显示核实提示，不转为“暂无匹配”。
- 包含小浮条与托盘恢复修改。旧安装包与用户数据未删除。

验证：103 项自动化测试通过，覆盖对比字段、证据不足、危险链接、MCP 往返、项目过滤及 UI 流程。测试使用虚构模型夹具，不代表已验收真实模型回答质量。真实桌面视觉与跨平台体验仍需试用确认。
