# TechCompass

**新技术与我正在做的项目，到底有什么关系？**

给正在用 AI Agent 做产品、写代码的独立开发者与设计师。输入一个技术词、GitHub 链接或截图，TechCompass 带上你的项目背景，解释用途，并帮助你决定：**现在尝试、以后再看，还是可以忽略。**

[下载安装包](https://github.com/fishwithoctopus/TechCompass/releases/latest) · [问题反馈](https://github.com/fishwithoctopus/TechCompass/issues) · [MIT License](LICENSE)

## 下载与开始

在 [Releases](https://github.com/fishwithoctopus/TechCompass/releases/latest) 选择：

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `TechCompass-Setup-0.4.10.exe`，或便携 ZIP |
| Mac Apple Silicon | 名称包含 `mac-arm64.dmg` 或 `mac-arm64.zip` |
| Mac Intel | 名称包含 `mac-x64.dmg` 或 `mac-x64.zip` |

安装前从托盘退出旧版。Windows 便携版需完整解压，不要只移动 EXE。Mac DMG 打开后将应用拖到 Applications。

安装包未签名，Mac 未公证，系统可能提示风险或阻止打开。请按设备和组织安全政策判断，不要关闭系统安全防护。Mac 构建成功不等于已完成真实设备验证。

1. 打开设置，检查本机 Codex / Claude Code，或配置兼容 OpenAI 的 API。
2. 接入 MCP 后，在 Agent 的项目会话里说：**“把当前项目注册进 techcompass”**。也可以从文件夹关联项目。
3. 查看项目摘要，确认目标、当前重点与技术栈。
4. 输入技术词、链接或图片，点击分析。
5. 阅读相关项目、理由与最小验证动作。项目进度变化时，在 Agent 中请求更新摘要，或在项目页刷新和纠正。

没有项目时也能先获得解释，再关联项目。不自动扫描全部磁盘，也不自动持续同步项目。

## 不只是“是什么”

| 你想知道 | 它如何回答 |
| --- | --- |
| 一个技术有什么用 | 简短解释、解决的问题、在项目中的替代或补充位置 |
| 新模型与旧版有什么不同 | 明确基准、变化与依据、代价、是否值得尝试 |
| 现在要不要投入 | 相关度与采用时机分开判断 |
| 暂时不用会不会错过 | 给出未来触发条件，而不是模糊地收藏 |
| 没有项目匹配 | 不硬凑相关性，用适用场景解释用途 |
| 名称含糊或是造词 | 先澄清来源与对象，不把未知当成无关 |

高相关也可以建议延后，例如项目即将交付时，不应仅因出现新框架就重写全部代码。

图片支持选择、拖放和粘贴，PNG、JPEG、WebP、GIF，最大 8 MB。等待时可主动开启贪吃蛇，离开或结果返回时暂停。该功能不会让模型更快，分析仍可能需要几十秒。

## 模型、联网与费用

TechCompass 不内置永久免费模型，不承诺免费或秒回。

| 分析方式 | 前提 | 联网能力 |
| --- | --- | --- |
| Codex CLI | 本机已安装、登录且有额度 | 技术词检索与分析可在一次调用中完成 |
| Claude Code CLI | 本机已安装、登录且有额度 | 当前关键词检索仍先借助 Codex |
| 自定义 API | 兼容 OpenAI 的地址、模型名、Key | API 不自动提供搜索，关键词检索仍依赖 Codex |
| 演示引擎 | 主动选择 | 预设模拟，不是真实搜索 |

直接链接会尝试读取原文，可能受网站权限或结构限制。真实引擎失败会明确提示，不悄悄降级为演示结果。CLI 调用不要求先打开 Agent 会话，但工具必须可用。

取消请求不保证撤销服务商已发生的用量。缓存结果会标注时间，项目更新后应刷新判断。

## MCP 与项目上下文

桌面卡片给人使用，MCP 给 Agent 使用，两者共享本地记录。设置提供宿主接入和通用配置，可用于支持相应 MCP 传输的客户端，不宣称兼容所有 Agent。

“完成注册配置”与“连接成功”分别检查。配置写入有备份与格式校验。不要将本机令牌、API Key 或带授权信息的连接配置公开粘贴到 Issues。

## 隐私与边界

- 项目摘要与分析历史保存在用户目录下的 `.techcompass`。
- **本地保存不等于离线分析**，输入及必要项目背景会发送给你选择的模型服务。
- 桌面端在操作系统加密能力可用时加密保存 API Key。
- 不监听剪贴板或浏览活动，不默认扫描整个磁盘。
- 反馈界面已移除，历史保存不代表训练模型或持续自我学习。
- 建议不会替你安装依赖、迁移代码或执行采用动作。重要结论应核对原始来源。
- 本产品尚未通过正式用户研究证明能改善焦虑或提升生产效率。

## 从源码运行

需要 Node.js 20+，模型工具需独立安装或配置。

```sh
git clone https://github.com/fishwithoctopus/TechCompass.git
cd TechCompass
npm ci
npm test
npm run card
```

- Windows 构建：`npm run dist:win`
- Apple Silicon 构建（Mac）：`npm run dist:mac:arm64`
- Intel 构建（Mac）：`npm run dist:mac:x64`

标签发布由 GitHub Actions 在 Windows 与 macOS 环境构建。产物先进入草稿 Release，核对后公开。

源码：`ui/` 桌面界面、`card/` Electron 外壳、`lib/` 本地核心、`mcp/` 接口、`site/` 展示页。测试示例项目不会自动导入用户项目。

自动化测试与真实模型质量、安装体验分开验收。Mac 真机安装、Keychain、图片粘贴与模型链路仍待验证。反馈问题请提供版本、系统、引擎与复现步骤，并遮盖个人路径、密钥和私有代码。
